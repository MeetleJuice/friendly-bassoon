## Research and scope

Revisited the official [Ollama API source](https://github.com/ollama/ollama/blob/main/docs/api.md) during this update. It documents response usage/durations, native chat/tool fields and model-specific thinking controls. The documentation alone does not prove the user's model/server accepts a thinking toggle, so this release measures output allocation and does not set one. Direct docs.ollama.com and the Anthropic eval article could not be fetched from this execution network; no fresh claims are attributed to those unavailable pages. Prior source research and engineering references remain indexed in maintenance/README.md.

Personal agents and credentials are preserved; managed saved IDs remain stable and are never overwritten, while fresh campaign snapshots carry crew2instructions. No database migration/new dependencies. No MCP, autonomous Ralph context reset, multi-agent orchestration, OS sandbox, retraining, portrait integration or automatic upload is claimed. Original image archival still needs the original file attachments/ZIP.
