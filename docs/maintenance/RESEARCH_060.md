## Acceptance boundaries

Static checks catch syntax, compile-time errors and obvious literal unpacking arity mismatches. They cannot certify runtime imports/dependencies, asset presence, graphics/audio, controls, resource availability or gameplay. A recovered edit does not erase its earlier errors. `last_read` is scoped to one run and exact resolved protected project path; an external change still blocks the write. Plan mode removes write/command advertisement and execution permission without rewriting saved agents. Existing data schema5/retention stays in place. Automatic cloud generation, transcription upload and text-to-tool execution remain prohibited.
