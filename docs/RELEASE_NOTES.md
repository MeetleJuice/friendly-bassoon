## Aigentics Desktop 0.5.0 — projects, source context and native tool tests

- **PROJECTS** remembers opened folders and short user-written project briefs. Workbench adds a recent-project chooser and project-scoped history. Existing project files are not moved or rewritten.
- **Project context** provides bounded, fresh source maps and cited lexical excerpts, with sensitive paths, links and project ignore rules excluded. Preview locally with no model/embedding calls; explicitly add reviewed excerpts to a task after hash/ignore revalidation. No source-body index is retained.
- **Tools & permissions** exposes the shared built-in registry. Builder and Reviewer templates include read-only map/retrieval tools; writes and commands retain reviewed approval. Existing saved agents are preserved.
- **Test model** requests a single synthetic native function call with a 96-token output limit. It cannot execute project tools. Remote generation needs explicit approval and may incur provider charges. Optional local Ollama comparison checks four matched native/compatible and stream/nonstream routes, with no hidden retries or transport changes.
- **Structured streaming** aggregates bounded native NDJSON/OpenAI SSE tool fields only, requiring complete streams. Printed JSON is never executed. Native tool IDs are preserved. A passing local route can be selected after confirmation, then checked against the full coding workflow.
- **Better evidence** includes actual HTTP status, environment, typed failure counters and Ollama parser/renderer/template_source from the existing metadata call. Browser sharing hides unnecessary token controls, preserves compact probe evidence and requires exact-preview approval.
- **Testing and memory** expands packaged diagnostics to 17 offline checks, adds schema 5 project definitions, updates maintenance research/plan/triage records and tests the actual released 0.4.0 installer upgrade, including saved catalogs/history.

The Qwen native-tool failure remains open until the user's matching live probe/workflow passes. A route difference is a hypothesis, not a promised fix. Vector embeddings, arbitrary MCP/plugin execution, agent teams and GitHub OAuth are deferred with explicit acceptance criteria in the upgrade plan. The installer remains unsigned.

After installing: open Test model, select the same Qwen agent, optionally enable the four-local-route comparison, run once and review/share the report with its model name. Cloud probes are optional and separately approved. Open your existing project once in PROJECTS and inspect its local context preview.
